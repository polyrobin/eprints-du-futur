Notice en strates

Une même notice décrite par six vocabulaires. Chaque vocabulaire est un plan, et une ressource occupe la même place sur chaque plan où elle est décrite : le trait vertical qui relie ses descriptions, c'est son identité. Les sources externes forment l'anneau extérieur. Faites tourner la vue, aplatissez-la pour voir les recouvrements, cliquez une ressource pour lire ses triplets.
